# 🧮 BMI Calculator using Python (Tkinter)

## 📌 Description
This is a simple GUI-based BMI (Body Mass Index) Calculator built using Python and Tkinter.  
It allows users to enter their weight and height, calculates BMI, and displays the corresponding health category.


## 🚀 Features
- User-friendly graphical interface
- Calculates BMI instantly
- Displays BMI category:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Input validation for incorrect or negative values
- Error popups for invalid inputs

---

## 🛠️ Technologies Used
- Python
- Tkinter (for GUI)

## ▶️ How to Run

1. Make sure Python is installed on your system

2. Run the program:
 
   bmi_calculator.py
